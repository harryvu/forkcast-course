Deep learning and PyTorch, one delivery app at a time.

Eighteen lessons that build the machine-learning backend of Forkcast, a food-delivery app: a delivery-time predictor, a dish-photo classifier, a review reader, a recommender, all behind one API. Written for developers who know Python and nothing about matrices yet.

Start with Lesson 0 See the syllabus

Colour means dimension. The same code is used in every diagram of the course:

  • batch N
  • features d
  • weights
  • outputs
  • channels C
  • spatial H, W

How a lesson works

  1. Read and play

    Each lesson page states its objectives, introduces one concept with live diagrams you can poke at, and asks you to predict shapes before you run anything.

  2. Build in Colab

    A button opens the lesson's notebook from your copy of the repository, and you write code into that copy, so the project grows with you from Lesson 0 to the capstone.

  3. Prove it is done

    Every lesson ends with a definition of done: commands whose output tells you whether you met the objectives, and a green check on GitHub when you push.

Point the links at your repository
